# Zauber lernen

| Feld | Wert |
|------|------|
| Zauberliste | https://www.d20srd.org/srd/spellLists/sorcererWizardSpells.htm |
| Dauer | 2d (1d identifizieren, nach erfolgreichem Check nochmal 1d zum Übertragen ins Zauberbuch) |
| XP-Kosten | keine |
| Gold-Kosten | 100g pro Spell-Level (und 1 Zauberbuchseite pro Spell-Level [100 verfügbar]) |
| Skill-Check | Spellcraft DC 15 + Spell-Level (+2 auf Spellcraft der spezialisierten Zauberschule) |
| Konsequenzen | Success – Schriftrolle ist verbraucht und Zauber gelernt / Fail – kann erst auf der nächsten Stufe nochmal ausprobiert werden |

Am Beispiel einer Identify Scroll:

| Feld | Wert |
|------|------|
| Dauer | 2d |
| XP-Kosten | - |
| Gold-Kosten | 100g |
| Skill-Check | Spellcraft DC 16 |

# Scribe Scroll

| Feld | Wert |
|------|------|
| Scroll-Liste | https://olddungeonmaster.com/2012/06/22/magic-items-prices/ |
| Dauer | 1 Tag pro 1000gp Schriftrollen-Preis |
| XP-Kosten | 1/25 des Gold-Preises + XP-Kosten des Spells (falls vorhanden) |
| Gold-Kosten | Hälfte des originalen Preises + Materialkosten des Spells (falls vorhanden) |
| Skill-Check | keiner |

Am Beispiel einer Scorching Ray Scroll:
| Feld | Wert |
|------|------|
| Scroll-Preis | 150gp |
| Dauer | 3.6h (150gp/1000gp*24h) |
| XP-Kosten | 6XP (150/25) |
| Gold-Kosten | 75gp (150gp/2) |
| Skill-Check | keiner |
